# MTrack

Локальный трекер спорта и поездок для Android: бег, ходьба, велосипед, самокат, поход, автомобиль, мотоцикл. Без аккаунта, сервера, рекламы и аналитики — все данные остаются на телефоне.

- Пакет: `com.moscilez.track`
- minSdk 26, targetSdk/compileSdk 36
- Языки: русский и английский (`values-ru`, `values`)

## Почему Kotlin, а не Java

Изначально просили Java. Приложение написано на Kotlin, потому что:

- Jetpack Compose (современный UI-тулкит Android) работает только с Kotlin — на Java пришлось бы использовать устаревшие XML-разметки.
- Корутины и Flow дают простую и безопасную асинхронность для GPS, базы данных и шифрования без ручных потоков и колбэков.
- Null-safety на уровне компилятора убирает целый класс падений (NullPointerException).
- Kotlin — официальный рекомендуемый язык Google для Android, все новые библиотеки Jetpack пишутся сначала под него.

Код на Kotlin полностью совместим с Java: при необходимости отдельные модули можно писать на Java.

## Архитектура

MVVM + Repository, ручной DI через `AppContainer` (`MTrackApp.kt`).

```
ui/         Compose-экраны и ViewModel (только через репозитории, без DAO)
domain/     Чистая логика без Android: GPS-фильтр, расчёты, статистика, цели, рекомендации, рекорды
data/       Room (сущности, DAO, миграции), репозитории
tracking/   Foreground Service записи GPS и общее состояние трекинга
transfer/   Экспорт/импорт архива, GPX, перенос по QR-кодам, шифрование
work/       Периодическое обслуживание базы (WorkManager)
```

- **Запись.** GPS работает в Foreground Service (`location`) с постоянным уведомлением. Каждая точка проходит `GpsFilter` (точность, дубли, порядок, невозможная скорость, дрожание) и сразу пишется в Room. Если процесс убит системой, незавершённая сессия находится при следующем запуске и продолжается без потери маршрута. Паузы делят маршрут на сегменты — дистанция между ними не считается.
- **База данных.** Room v2 с явной миграцией 1→2; destructive fallback выключен, чтобы история никогда не стиралась молча. Схемы лежат в `app/schemas`.
- **Карта.** Улицы OpenStreetMap (osmdroid) с маршрутом поверх. Тайлы кешируются на устройстве (до 300 МБ), поэтому просмотренные районы видны и без сети; без сети в новом месте маршрут всё равно рисуется на однотонном фоне.

## Приватность

- Интернет используется только для загрузки картографических тайлов OpenStreetMap. Координаты, тренировки и профиль никуда не отправляются (тайл-сервер видит лишь запрошенный участок карты).
- Нет авторизации, бэкенда, Firebase, аналитики и рекламы.
- Разрешения: геолокация (запись), уведомления (статус записи), камера (только приём по QR).

## Перенос данных

- **Архив**: zip, зашифрованный AES-256-GCM, ключ из пароля (PBKDF2). Перед импортом показывается превью; режимы «объединить» (дубликаты по UUID пропускаются) и «заменить».
- **GPX**: экспорт отдельных активностей.
- **QR-коды**: телефон-отправитель показывает серию кодов и одноразовый код из 10 символов; получатель сканирует камерой. Кадры принимаются в любом порядке, прогресс переживает сворачивание приложения. Целостность проверяется CRC32 на кадр, SHA-256 на пакет и тегом GCM на содержимое.

## Тесты

JVM-тесты (`app/src/test`) — доменная логика и перенос:

- `TrackMathTest`, `GpsFilterTest` — расстояния, темп, фильтрация GPS
- `StatsAndGoalsTest` — периоды, итоги, серии, цели, личные рекорды
- `PasswordCryptoTest`, `QrCodecTest` — шифрование, коды, сборка QR-кадров

```
./gradlew testDebugUnitTest
```

Инструментальные тесты (`app/src/androidTest`) — DAO на in-memory Room, миграция 1→2, запуск приложения:

```
./gradlew connectedDebugAndroidTest
```

Проверка покрытия переводов: `python3 scripts/check_strings.py`.
