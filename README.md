# MTrack

Локальный Android-трекер активности на Java. Проект использует MVVM-совместимую слоистую основу, Room для локальных данных и Foreground Service для записи активности.

## Первый вертикальный срез

- локальный профиль без аккаунта;
- Dashboard, выбор режима, запись и завершение активности;
- история из Room;
- русский UI-скелет и подготовленная локализация;
- foreground GPS-service с восстановлением процесса через `START_STICKY`.

## Сборка

```text
gradlew.bat assembleDebug
```

Следующий этап: полноценная запись GPS-точек порциями, вычисление метрик, экран деталей, импорт/экспорт и тестовый контур.
